# 小说作者手册

> 这份手册写给小说作者，不讲代码。所有操作都能在网页工作台（Writer Assistant Studio）里完成；命令行的用法只作为补充列出。读完大约 15 分钟，能覆盖日常写作的全流程。

## 一、工作台怎么运转

Writer Assistant 把一部作品分成两层：

- **确认版真源**（你和 AI 都能读、都要遵守）：`大纲`、`角色`、`世界设定`、`作者意图`、`创作罗盘`。
- **运行态**（AI 干活的现场）：`正文草稿`、`章节记忆`、`审稿记录`、`快照`。

**两个 AI 角色分工明确：**

- **Goethe（规划）**：和你聊书名、冲突、人物、大纲，把灵感整理成可写资产，资产成熟后交给 Dante。
- **Dante（写作）**：负责预检、写章、审稿、修订和状态结算。

**一切改动可回滚。** 每次写章都有快照，改坏了随时退回上一版，不会丢稿。

## 二、开一本新书（约 30 分钟）

1. **打开工作台**：双击 `启动 Writer Assistant.bat`（Windows，独立桌面窗口），或命令行运行 `writer studio`。
2. **配置模型**：首次打开会引导你配置 AI 模型（见第六节）。配置一次，长期有效。
3. **创建作品**：输入书名和一句话简介，工作台会生成初始目录。
4. **先和 Goethe 聊**：在「AI 协作」面板进入 Goethe，聊书名、核心冲突、主要人物、想写的题材。不要急着写正文——大纲越扎实，后面越顺。
5. **检查资产就绪度**：命令行 `writer desk` 会列出还缺什么（角色卡、世界设定、风格等），照着补齐。
6. **写第一章**：资产齐了之后，让 Dante 开始。AI 会先预检（大纲、事实、伏笔、连续性），再动笔。

## 三、日常写作流

### 一个完整循环

```
Goethe 规划 → 大纲定稿 → Dante 预检 → 写章 → 审稿 → 修订 → 结算
```

- **预检**：每次写章前，Dante 会检查最新大纲、已确认事实、待收伏笔和人物连续性，防止"写着写着就偏了"。
- **写章**：正文在「正文」视图里以 Markdown 编辑，支持自动保存。
- **审稿**：写完一章去「审稿」视图。AI 按逻辑、连续性、伏笔、风格打分（满分 100），列出具体问题并定位到行。有严重问题会提示重写；分数从 100 起，每个严重问题扣 20 分、每个警告扣 5 分。
- **修订**：按 issue 逐条改，或要求 Dante 修订后复评。
- **结算**：每章写完后状态自动推进（规划 → 起草 → 已审），「总览」视图的进度条同步更新。

### 中途改变主意（连续写作干预）

想让 AI 换个方向，不用打断整个会话：

```bash
writer run list                                    # 查看正在进行的写作任务
writer run intervene <run_id> <revision> "改写成更压抑的基调" --risk medium
writer run transition <run_id> <revision> <id> done  # 干预已落实
writer run cancel <run_id> <revision>              # 取消当前任务
```

也可以直接在「AI 协作」面板里对话说明意图，Dante 会记录为创作干预并执行。

### 阶段目标（创作罗盘）

```bash
writer focus set "本阶段：第一卷铺垫，保持悬疑感，主角不暴露身份"
```

这条约束会注入每一章的写作上下文，直到你主动更换。比每次口头叮嘱可靠得多。

## 四、风格库：让 AI 学你的文风

- **提取**：把你的一段文字（或别人的示范文本）交给工作台：`writer style extract`（Studio 里在「风格档案馆」操作）。它会提炼用词、句式、节奏、对话、叙述距离等写作信号。
- **隔离**：你的作品专属内容（人名、世界观、口癖）会被自动隔离出去，不会污染风格档案。
- **命名与选用**：每份档案可以命名（如"冷峻都市风"、"散文式慢节奏"），写作时选中即注入上下文，不需要重新调教 AI。
- **合成**：多份样本可以合并成一份更完整的档案：`writer style synthesize`。

## 五、设定与素材的保鲜

- **事实一致性**：写章后自动抽取事实并与真相库交叉校验，冲突直接进审稿 issue——不用等连载几十章才发现人物眼珠子颜色变了。
- **连续性视图**：人物、组织、地点的关系拓扑图，点开任意节点查看与它相关的所有文本位置。
- **灵感素材板**：研究、参考、世界设定、伏笔、风格五类资产聚合在一个视图，最近更新优先，点击卡片直接打开编辑。
- **写作仪表盘**：章节字数柱状图、审稿分数折线图、剧情预测列表（narrative forecast）——一眼看清创作节奏与质量走向。
- **项目搜索**：语义检索（不仅关键词，还懂同义表达），结果精确到文件与行号；没有网络或模型时自动降级为文本搜索，并提示你。
- **大纲即真源**：左侧「大纲」直接编辑 `src/outline.md`；删除含正文的章节会被阻止，防止误操作。

## 六、模型配置

在「模型设置」里配置（总览右上角）：

- **服务商与密钥**：支持主流大模型服务，密钥只保存在本地配置里。
- **不同任务用不同模型**：规划、写作、审稿可以分别指定，例如写作用更强的模型、审稿用更快的模型。
- **温度**：写作可调高一点更自由；审稿建议调低保持稳定。
- **离线可用性**：网络不可用时，搜索等能力自动降级为本地文本处理，不影响写作。

## 七、备份、诊断与迁移

- **正文版本**：每次写章自动存档。改坏了随时恢复：`writer version list <章节>` 查看历史版本，`writer version restore <章节> <版本>` 恢复（恢复前会自动备份当前正文，不会直接覆盖）。
- **诊断包**：遇到问题时，在「高级工具」里点「导出诊断包」，自动收集日志、配置（已脱敏）和版本信息——把它发给维护者即可定位问题。
- **项目迁移**：可以把作品目录移动到任意位置；命令行统一加 `--project <作品目录>`，或使用「项目迁移」视图可视化搬迁。
- **导出成书**：`writer export --format md` 输出整本书的 Markdown；其他格式可在「高级工具」里处理。
